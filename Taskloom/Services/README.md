# Services

Папка для прикладных сервисов, координирующих работу доменной модели, данных и presentation-слоя.

Текущий состав:

- `Localization` - контракты локализации пользовательских строк
- `Records` - абстракции для работы с календарными записями
- `CalendarRecordService` - прикладные сценарии CRUD и фильтрации
- `Settings` - контракты хранения настроек приложения
