# Infrastructure

Папка для инфраструктурных реализаций: подключения к SQLite, репозиториев и технических компонентов.

Текущий состав:

- `Localization` - загрузка языков и источник строк для WPF
- `Storage` - пути хранения, фабрика подключений и инициализация SQLite
- `Settings` - хранение настроек приложения
- `Repositories` - реализации репозиториев на SQLite и Dapper
